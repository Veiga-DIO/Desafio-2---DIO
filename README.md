# Organizador de Declaração de Imposto de Renda, utilizando Excel.
## Descrição do Desafio
Construir uma ferramenta no Excel para organizar e controlar dados para o Imposto de Renda, de forma fácil e eficiente.
## Objetivos do Desafio
Desenvolver um sistema, no Excel, para estruturar dados relacionados ao Imposto de Renda, utilizando mecanismos de validação e recursos de navegação que proporcionam confiabilidade, sistematização e fluidez no controle das informações do titular e/ou dependentes.
## Aprendizado
Validação de Dados, Menus de Navegação, Listas Suspensas, Links Rápidos de Navegação, Organização, Layout etc.
## Intruções de Uso
No Excel, abra o arquivo;
Na aba TITULAR, preencha com os dados pessoais;
Na aba INFORMES, preencha com as informações referentes aos dados bancários;
Na aba NOTAS, informe os valores de holerites;
Na aba DESPESAS, informe as despesas médicas, educacionais etc. realizadas no Ano-Exercício.
